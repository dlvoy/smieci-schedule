## [1.0.0] - 2026-08-31

### Added

- Initial release: Home Assistant custom integration for the smieci.example.com
  waste-collection schedule — per-fraction date/status sensors, a "take it out"
  binary sensor, configurable notification targets, and colored bin icons
  reflecting scheduled/tomorrow/today state.
- HACS custom-repository support, plus a manual install script for non-HACS
  Home Assistant setups.
